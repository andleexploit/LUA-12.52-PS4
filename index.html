📌 Overview

This repository contains the complete documentation, scripts, and findings from an intensive research project targeting the PlayStation 4 firmware 12.52. The goal was to discover a new kernel exploit from scratch using only the remote_lua_loader as an entry point, completely avoiding WebKit and BD-J.

While a full jailbreak (Kernel R/W -> GoldHEN) was not achieved due to missing public kernel offsets and primitives for this specific firmware, this repository serves as a comprehensive map of the sandbox. It documents exactly what works, what is patched, and what vectors are still theoretically viable for future researchers.

🏆 Achievements (What Works)

  • Complete Userland R/W: Using Lua 5.1 primitives (memory.read_buffer, memory.write_buffer).
  • Object Manipulation: addrof, fakeobj, and create_fake_cclosure are fully functional.
  • KASLR Bypass: Successfully leaked kernel pointers and mapped fixed bases (Kernel Leak: 0xffffffffb8fd86f0).
  • Sandbox Mapping: Fully documented the Event Flag family (Syscalls 538, 539, 544, 548, 638).

💀 Dead Ends (What is Patched)

  • Event Flag UAF: Syscalls 544 and 548 do not write to the allocated object. Heap grooming is prevented by UMA.
  • IPv6 NetControl: setsockopt with IPV6_PKTOPTIONS, HOPOPTS, DSTOPTS, and RTHDR return EPERM or EINVAL.
  • Lua 5.3 CVEs: Public Lua CVEs are fully patched by Sony's custom implementation.
  • Driver IOCTLs: /dev/gc, /dev/dce, and /dev/dmem return -1 for all commands.

🔬 The Promising Vector: AIO Multi-Cancel (Syscall 601)

We discovered a deterministic crash in aio_submit (Mode 3). Calling 601(3, ...) immediately crashes the application (SIGSEGV in userland, not a kernel panic). This indicates a missing validation check in the kernel's AIO submission queue. The goal for future work is to control the structure passed to Mode 3 to trigger a Use-After-Free (UAF) and reclaim the freed slot with a controlled object.

4. Driver IOCTL Check (05_driver_fuzzer.lua)

local candidates = { "/dev/gc", "/dev/dce", "/dev/dmem0" }
local generic_ioctls = {
    {name="FIONBIO",  cmd=0x8004667E},
    {name="FIONREAD", cmd=0x4004667F},
    {name="raw0", cmd=0},
}
for _, dev in ipairs(candidates) do
    local fd = syscall.open(dev, 2, 420):tonumber()
    if fd >= 0 then
        for _, gi in ipairs(generic_ioctls) do
            local rv = syscall.ioctl(fd, gi.cmd, gbuf_addr):tonumber()
            if rv ~= -1 then print("Vulnerable: " .. dev) end
        end
    end
end
